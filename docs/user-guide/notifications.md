# 알림 확인하기 사용 설명서

| 항목 | 내용 |
|---|---|
| 대상 | 고객(회원) |
| 화면 주소 | PosSelect 모든 화면 위쪽의 공통 머리말 — 예: <https://home.posselect.com> |
| 필요한 권한 | 로그인만 |
| 최종 확인 | 2026-10-04, 배포 커밋 `087d3f6` 에서 실제 화면으로 확인(결제 → 숫자 표시 → 목록 → 알림 눌러 이동). 「모두 읽음」은 (미확인) — 시험 화면에서만 확인 |
| 관련 이슈 | lee-dohyun/posselect-shell#79, lee-dohyun/posselect-shell#83, lee-dohyun/gateway#180 |

## 1. 이 기능으로 할 수 있는 일
결제가 끝나면 화면 위쪽 종 모양 「알림」 버튼에 새 알림이 쌓입니다.
버튼을 눌러 알림을 읽고, 알림을 누르면 마이페이지로 이동합니다.

## 2. 시작하기 전에
- 로그인이 필요합니다. 로그인하지 않은 상태에서 「알림」을 누르면 로그인 화면으로 이동합니다.
- 비회원으로 주문한 건은 알림이 남지 않습니다 — 알림함은 회원 계정에 딸려 있기 때문입니다.

## 3. 따라 하기
### 3-1. 새 알림 확인하기
1. 화면 위쪽 「알림」 버튼을 봅니다. → 안 읽은 알림이 있으면 버튼에 숫자가 붙습니다(100개 이상이면 `99+`).
2. 「알림」 버튼을 누릅니다. → 알림 목록이 열립니다. 안 읽은 알림은 굵은 글씨와 파란 점으로 표시됩니다.
3. 알림을 누릅니다. → 그 알림이 읽음으로 바뀌고 숫자가 하나 줄어듭니다. 이동할 곳이 있는 알림은 그 화면(주문 알림은 마이페이지)으로 이동하고, 도착한 화면에서도 숫자가 줄어 있습니다.

### 3-2. 한꺼번에 읽음 처리하기
1. 알림 목록 오른쪽 위 「모두 읽음」을 누릅니다. → 버튼의 숫자가 사라지고 모든 알림이 읽음으로 바뀝니다.

### 3-3. 목록 닫기
1. 목록 바깥을 누르거나 「알림」 버튼을 다시 누릅니다. → 목록이 닫힙니다.

## 4. 입력 항목 설명
해당 없음

## 5. 상태와 진행 흐름
| 상태(화면 표시) | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 굵은 글씨 + 파란 점 | 아직 읽지 않은 알림 | 눌러서 확인 / 고객 |
| 흐린 글씨 | 읽은 알림 | 없음 |

현재 오는 알림은 한 가지입니다.

| 알림 제목 | 언제 오나 | 내용 |
|---|---|---|
| 「결제가 완료되었습니다」 | 주문 결제가 끝난 직후 | 「주문 #주문번호 · 결제금액」 |

## 6. 자주 보는 메시지와 해결 방법
| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|
| 「불러오는 중…」 | 알림 목록을 받아 오는 중 | 잠시 기다립니다 |
| 「새 알림이 없습니다」 | 받은 알림이 없거나, 목록을 받아 오지 못함 | 방금 결제했는데 이 메시지가 보이면 목록을 닫았다가 다시 엽니다 |

## 7. 알아 둘 제한 사항
- 버튼의 숫자는 1분마다 새로 확인합니다 — 결제 직후 숫자가 바로 바뀌지 않을 수 있습니다. 「알림」 버튼을 누르면 그 자리에서 최신 목록을 받아 옵니다.
- 목록에는 최근 알림 20개까지만 보입니다 — 머리말에 붙은 작은 창이라 지난 알림을 넘겨 보는 기능은 없습니다.
- 알림 시각은 「방금 전」 「n분 전」 「n시간 전」 「n일 전」으로 보이고, 일주일이 지나면 날짜로 보입니다.
- 결제 완료 메일과 알림은 따로 보냅니다 — 한쪽이 오지 않아도 다른 쪽은 올 수 있습니다.
